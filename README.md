## About

This project contains my Week 2 internship task on creating an Incident Response Plan.

The objective of this task is to understand how an organization should respond to a cybersecurity incident and to create a clear, structured process for handling cyber attacks.

## Topics Covered

- Incident Response Preparation
- Incident Detection and Reporting
- Incident Classification
- Incident Analysis
- Containment
- Evidence Preservation
- Eradication
- Recovery
- Communication and Escalation
- Ransomware Response
- Phishing Response
- Malware Response
- Data Breach Response
- DDoS Response
- Post-Incident Review
- Incident Response Checklist

## Framework Used

The plan is based on established incident response practices, including NIST SP 800-61 Rev. 3 and the NIST Cybersecurity Framework.
